# NisaraAI Studio Agent Core

A modular, production-ready AI agent framework designed for browser intelligence, system compatibility, and self-evolving automation workflows.

## Overview

NisaraAI Studio Agent Core is a lightweight but extensible Python architecture for building autonomous AI systems. It integrates a multi-layer execution pipeline with built-in compatibility handling, simulated browser intelligence, and evolution-aware optimization logic.

The system is designed to be easily upgraded into real-world production environments (Firebase, Node.js services, API gateways, or cloud-based AI agents).

## Key Features

- **Modular Agent Architecture** – Clean separation of browser, logic, and evolution layers  
- **Compatibility Engine** – Handles legacy, mixed, and dynamic input formats safely  
- **Browser Simulation Layer** – Structured web query handling with sanitization pipeline  
- **Evolver System** – Memory pruning, configuration optimization, and self-improvement hooks  
- **Execution Pipeline** – Multi-stage processing (parse → route → execute → optimize → log)  
- **Rollback Support** – Safe state reversal for controlled execution recovery  
- **Exportable State** – JSON-based state snapshot for persistence or syncing  

## Architecture

- Agent Core (`NisaraAgent`)
- Compatibility Layer (`CompatibilityLayer`)
- Browser Engine (`BrowserEngine`)
- Evolver Engine (`Evolver`)
- State Manager (`AgentState`)

## Execution Flow

1. Input normalization  
2. Intent parsing  
3. Routing (LLM / Browser mode)  
4. Execution  
5. State optimization  
6. History logging
